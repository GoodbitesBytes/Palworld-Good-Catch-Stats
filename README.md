# Palworld Good Catch Stats

A Palworld mod that tracks special characteristics of Pals you successfully capture.

## Planned Stats

For each Pal species, Good Catch Stats will track:

- ⭐ Alpha captures
- ♂️ Male captures
- ♀️ Female captures
- ✨ Lucky captures

Stats will be displayed in Paldpedia order rather than alphabetical order.

## Status

🚧 Currently in development.

The capture detection systems are being developed and tested before the full stats interface is completed.

## Requirements

- Palworld
- UE4SS
